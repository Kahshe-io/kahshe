Kahshe

An index and search system for Iceberg tables. This document defines the mark, the typeface, and a two-accent colour system where cold carries identity and warm means a match — and nothing else gets colour at all.

01

The mark

The name inside square brackets. The brackets are set in the mono weight of the same family, so they stay squarer and more mechanical than the letters they enclose — the detail that keeps this from being a generic bracketed wordmark.

Primary

Ink name, teal brackets. The default everywhere.

Indexed

With subscript zero — array access. Use where the mark stands alone with no tagline.

One colour

All ink or all white. Laser, stamp, embroidery, dark UI chrome.

Clearspace and minimum size

Clear space on all four sides equals the height of a bracket. Minimum wordmark width 90px; below that, use the icon.

Construction — spacing is not symmetrical

The two bracket gaps are deliberately unequal. k meets the opening bracket with a flat vertical stem; e is x-height only and sits between the closing bracket's arms, so its nearest neighbour is the far-off stem. Equal measured gaps read as unequal white. These values equalise the white area instead, which is what the eye actually judges.

JunctionInk gap · average white
[ → k0.2163em — 21.45px average white at 52pt
e → ]0.1177em — 21.45px average white. Roughly half the left gap, and correct.
Icon [ → k0.150em — symmetrical. The tile crops the composition, so the frame reads as a frame and even gaps are the stronger cue.
Icon k → ]0.150em — plus a 1.6px downward nudge so the k sits on the tile's optical centre.
Tracking−0.03em across the word. The ka pair runs slightly open and cannot be tightened — its minimum gap is already 0.62px.

Do not normalise these to match each other. Use the supplied SVGs rather than setting the mark in live type.

Never

NOLetterspace the name. Tracking stays −0.03em.
[kahshe]
NOSet in capitals. Lowercase, always.
{kahshe}
NOSwap bracket type or weight. Square, mono, regular.

NOAmber brackets. Amber never carries identity.

03

Typeface

IBM Plex Sans and IBM Plex Mono, both SIL Open Font License — which permits logo use, embedding, and redistribution. That matters for a mark that lives in a repository: the licence travels with it.

Plex was drawn for a computing company and reads engineered rather than fashionable. Its mono has properly squared brackets, which is the entire mechanism of this wordmark. The shipped logo files are outlined paths generated from these metrics, so they carry no font dependency at render time.

Fallbacks

Inter, then system sans. For mono: JetBrains Mono, then ui-monospace. Both OFL.

Rejected

Inter — safe but voiceless. Geist — reads as Vercel's. Space Grotesk — too much personality for infrastructure.

Weights

Four only: Sans 400/600, Mono 400/500. Anything else is drift.

04

Colour

Two accents, one job each. Teal is identity and structure. Amber is a match and nothing else. Everything else in the system is neutral — if something is coloured, something is true about it.

Ink#0C1417Text, dark grounds, the icon tile
Teal#12727CBrackets, links, focus, active state
Teal tint#5FBFC7Teal's stand-in on dark grounds only
Signal#F0A62BA match — on dark grounds only
Signal deep#8A5A0FA match, on light grounds
Grey#647579Secondary text, metadata, everything else

Discipline

A two-accent system only works while the split holds. These are the rules that keep it from rotting into decoration.

ColourPermitted use
TealBrackets in the wordmark, links, focus rings, active nav, section numbers, and the tool's own voice in CLI output. Never on a value, a count, or a result.
AmberA hit count, a matched row, a highlighted partition, the file that was actually read. Never a heading, a button, a logo, or a chart series that isn't a match.
NeutralsEverything else, without exception. Surfaces, rules, metadata, secondary text, disabled states, and every chart series that isn't the match.
BothNever on the same element. If something is both identity and result, it is a result — amber wins, teal steps back.
A thirdMeans you found a new state. Name the state before you colour it. Errors take red from the system palette, not amber — amber must keep meaning "found".
PairRatio
Ink on white18.6:1 · AAA
Teal on white5.6:1 · AA
Teal tint on ink8.6:1 · AAA
Signal on ink9.0:1 · AAA
Signal deep on white5.9:1 · AA
Signal on white2.1:1 · fails — never do this
Grey on white4.8:1 · AA body text

Bright amber is unreadable as text on white. On light grounds a match uses Signal deep for the text and a pale amber wash behind the row — never bright amber type.
